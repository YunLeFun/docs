# 审核与上架规范

审核规范用于保证云乐坊工坊中的应用可访问、可信任、对用户有清晰价值。

## 基本要求

- 应用链接可访问，首屏无明显错误。
- 应用名称、简介、图标与实际功能一致。
- 不冒用他人品牌、作品或身份。
- 不包含违法、欺诈、恶意跳转、诱导下载或明显低质内容。
- 如收集用户数据，应提供清晰说明并遵守相关法律法规。

## 链接要求

- 优先使用 HTTPS。
- 不应强制用户下载未知文件。
- 不应跳转到与应用说明无关的页面。
- 备用链接仅用于主链接不可用时的兜底。

## 支付与会员

如果应用使用云币、会员或支付能力，应遵守平台账户中心约束：

- 不在前端信任任意金额或扣费参数。
- 按次扣费必须使用业务幂等键。
- 会员权益由应用定义，但会员事实来自平台账户中心。
- 不得承诺云币提现、转账或兑换人民币。

## 驳回与重新提交

被驳回的应用会显示驳回原因。开发者修正后重新保存，应用再次进入审核队列。
