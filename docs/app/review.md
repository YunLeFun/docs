# 审核与上架

云乐坊审核的是一次投稿的具体版本。个人作品保存、审核通过和云乐坊上架分别生效。

## 审核状态

| 状态 | 含义 | 维护者应做什么 |
| --- | --- | --- |
| `draft` | 已保存作品版本，尚未投稿 | 检查资料后主动投稿 |
| `pending` | 已投稿，等待处理 | 等待审核 |
| `in_review` | 正在审核 | 根据反馈补充说明 |
| `changes_requested` | 需要修改 | 保存修订版本并重新投稿 |
| `approved` | 该版本审核通过 | 关注是否已上架 |
| `rejected` | 该次投稿驳回 | 阅读原因，修正后重新投稿 |
| `withdrawn` | 投稿已撤回 | 如仍需上架，再次发起投稿 |

云乐坊展示状态包括 `unlisted`（未上架）、`listed`（已上架）、`suspended`（暂停展示）和 `delisted`（已下架）。审核通过并不自动保证展示，不能用旧版 `isPublic` 与 `status` 两个字段判断所有目录权限。

## 投稿前自检

- 名称、简介和图标准确描述当前应用，不冒用品牌或维护者身份。
- 主地址、隐私政策与支持入口使用可访问的 HTTPS 链接，首屏能完成所描述的功能。
- 标明测试版、登录要求或邀请限制；备用链接指向同一应用。
- 说明会收集的数据、所需权限和处理方式，提供用户可用的支持渠道。
- 如涉及云币或会员，明确价格和权益，由服务端校验账户与业务结果。

HTTPS 是保存资料的校验要求，不能作为应用可信任或获得原生授信权限的证明。来源授权、应用归属和账号能力由对应服务独立验证。

## 审核后的变更

个人主页与个人工坊会采用当前保存版本；云乐坊继续采用已批准上架的版本。新版本需再次投稿，避免修改个人资料时直接绕过公开目录审核。

暂停或下架后不能靠重复投稿同一个已审核版本恢复展示，应根据后台反馈联系维护者或提交修订版本。
