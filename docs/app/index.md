# 应用接入概览

云乐坊以 Web 地址分发应用。应用目录提供名称、图标、简介和打开入口，应用网站仍负责自己的运行环境、登录与数据。

::: info 当前阶段
第三方自助入驻尚未开放。公开作品当前按第一方域名范围校验，SSO 与计费能力也需单独登记和授权。接入说明不代表提交后一定上架。
:::

## 三种展示位置

| 位置 | 展示范围 | 使用的版本 |
| --- | --- | --- |
| 云乐坊 | 审核通过且已上架的公开应用 | 最近获准上架的版本 |
| 个人主页 | 坊主当前发布的公开作品 | 当前保存的作品版本 |
| 个人工坊 | 坊主与有效坊客可见的作品 | 当前保存的作品版本 |

保存作品和投稿云乐坊是两个动作。个人展示可以更新当前版本；云乐坊目录使用获准上架的版本，更新投稿审核期间继续展示原已上架版本。

## 选择接入路径

- 管理作品：阅读[提交流程](/app/submission)与[审核规范](/app/review)。
- 分享受限作品、管理坊客：阅读[个人工坊](/app/workshops)。
- 在其他页面展示公开应用：阅读[目录接口](/app/catalog)。
- 在 App 容器中适配布局、返回和原生能力：阅读 [JSAPI](/app/jsapi)。
- 需要跨应用登录或计费：阅读[账号与支付](/account/)，确认各项授权后再接入。
