# 应用接入概览

云乐坊支持把 Web 应用作为云应用接入工坊，用户可以发现、安装并从自己的云居桌面打开。

## 接入对象

适合接入的应用通常具备以下条件：

- 有稳定的公开访问地址。
- 应用内容、功能和 UI 已达到可展示状态。
- 能提供清晰的应用名称、简介、图标、分类和维护者信息。
- 如涉及登录、付费或会员能力，能遵守云乐坊统一账号和支付体系的约束。

## 基本流程

1. 开发者准备应用资料。
2. 通过工坊提交应用。
3. 应用进入审核队列。
4. 审核通过后，对外公开展示。
5. 用户在工坊或寻乐发现应用，并安装到云居桌面。

## 数据归属

应用目录以 CloudBase `apps` 集合作为事实源。对外开发者只需要关注公开字段和提交流程；内部运营审核、推荐榜单和离线快照生成属于云乐坊内部流程。
