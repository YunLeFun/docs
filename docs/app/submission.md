# 应用提交流程

创建和更新作品要求正式登录、已验证手机号且账号可用。入口在[云乐坊 App](https://apps.yunle.fun)的应用创作页面；第三方入驻尚未开放。

## 准备资料

| 字段 | 当前校验与用途 |
| --- | --- |
| 名称 | 必填，最多 50 字符，展示名称全局唯一 |
| `slug` | 2–50 字符，小写字母开头，仅小写字母、数字和连字符；创建后保持稳定 |
| 简介 | 最多 300 字符，说明应用实际用途 |
| 访问地址 | 必填 HTTPS URL，不含账号密码；公开第一方作品须属于 `yunle.fun` 或其子域 |
| 隐私政策、支持入口 | 均为必填 HTTPS URL；提供可读的说明与联系途径 |
| 图标 | 完整图标、可选主体图标与深色版本；无图标时使用 emoji |
| 主题色 | `#RRGGBB`，用于目录和宿主展示 |
| GitHub 仓库 | 可选，格式为 `owner/repo` |
| 分类、标签、备用地址 | 帮助发现应用；备用地址同样使用 HTTPS |

名称和 `slug` 的最终唯一性由服务端校验；前端显示“可用”后保存仍可能遇到占用冲突。网址中的 fragment 不作为应用地址保存。

## 选择分发属性

| 属性 | 可选值 | 含义 |
| --- | --- | --- |
| 可见范围 `audience` | `public` / `workshop` / `owner` | 个人主页公开 / 仅坊主和有效坊客 / 仅本人管理视图 |
| 访问方式 `accessMode` | `public` / `login_required` / `invite_only` | 网站无需登录 / 需要登录 / 邀请访问的展示说明 |
| 发布阶段 `releaseStage` | `stable` / `beta` | 稳定版或 Beta 预览阶段，不决定环境与计费行为 |

可见范围控制目录元数据；访问方式描述目标网站，不能代替网站自身鉴权。选择 `workshop` 前需开启[个人工坊](/app/workshops)。

## 保存与投稿

1. 保存资料，生成不可变的作品版本，个人展示按新版本和所选范围生效。
2. 需要进入云乐坊目录时，单独选择“投稿云乐坊”。只有公开作品可以投稿；将受限作品改为公开前，应确认内容可以对外展示。
3. 投稿进入审核队列，查看审核结果和修改意见。待修改或驳回后，保存修订版本并再次投稿。
4. 审核通过和上架是独立步骤，最终以目录中实际展示的已批准版本为准。

## 更新与移除

更新个人作品不会自动替换云乐坊的已上架版本。需要更新公开目录时再次投稿，审核期间原上架版本继续展示。

把可见范围改为 `workshop` 或 `owner` 会撤销云乐坊公开展示。下架操作会从目录移除作品并保留提交记录；它不会删除目标网站、撤销网站登录或清除用户已保存的 URL。
