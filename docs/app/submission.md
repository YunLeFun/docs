# 应用提交流程

应用提交入口规划在 `apps.yunle.fun` 的工坊中。

## 提交前准备

| 字段 | 说明 |
| --- | --- |
| 应用名称 | 面向用户展示的名称 |
| slug | 应用唯一标识，用于 URL 和安装记录 |
| 简介 | 一句话说明应用用途 |
| 访问地址 | 应用的公开 Web 地址 |
| 图标 | Logo URL 或 emoji |
| 分类 | 工具、效率、娱乐、教育等 |
| GitHub 仓库 | 可选，格式为 `owner/repo` |

## 状态流转

| 状态 | 说明 |
| --- | --- |
| `pending` | 已提交，等待审核 |
| `approved` | 审核通过，满足公开条件后可展示 |
| `rejected` | 审核驳回，开发者可查看原因后修改再提交 |

编辑应用会重新进入 `pending` 状态，避免已公开应用绕过审核直接变更。

## 公开条件

应用需要同时满足：

- `isPublic = true`
- `status = approved`

只有满足以上条件，应用才会进入公开目录、工坊搜索和运营推荐候选列表。

## 提交后

提交后请关注审核状态。如果被驳回，根据驳回原因修正后重新提交。
