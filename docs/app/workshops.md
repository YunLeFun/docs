# 个人工坊

个人工坊用于把作品分享给坊客。它与面向所有人的云乐坊上架目录分别管理。

## 开启与分享

在云乐坊 App 的“个人工坊”管理页开启工坊，设置名称、简介和加入方式，复制固定分享链接或二维码。作品选择 `workshop` 可见范围后，仅坊主与有效坊客能读取目录资料和打开入口；`public` 作品也会在工坊中展示，`owner` 作品仅在本人管理视图出现。

## 加入方式

| 策略 | 用户加入方式 |
| --- | --- |
| `approval`（默认） | 用户主动提交申请，坊主批准后成为坊客 |
| `open` | 获得链接的正式登录用户可直接加入 |
| `closed` | 暂停接受新坊客 |

切换加入方式不会改变已有坊客状态。开启 `open` 前应确认分享链接可以传播；它仍要求登录，但无需坊主逐人审批。

坊主可审批或管理成员，坊客可主动退出。停用工坊会暂时关闭坊客的作品列表访问，成员关系保留。

## 访问边界

非坊客可以看到工坊名称、坊主资料、简介和加入方式，不能获取受限作品的目录元数据或 URL。

工坊保护的是平台目录。已经知道目标网站 URL 的人仍可能直接打开网站，因此私密内容必须由应用网站自行校验登录和访问权限；仅把作品标为 `workshop` 或 `owner` 不能保护一个无需鉴权的静态页面。

个人工坊也不会自动授予 SSO、计费或原生授信能力，需要这些能力时另行确认接入条件。
