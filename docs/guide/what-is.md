# 文档定位

本站记录云乐坊已经实现的应用分发、统一账号与原生容器能力，供应用维护者接入和排查问题。公开文档不等于第三方接入已经开放。

## 当前开放范围

| 能力 | 当前范围 | 文档 |
| --- | --- | --- |
| 应用目录 | 浏览已上架应用，匿名读取公开目录 | [目录接口](/app/catalog) |
| 应用创作与个人工坊 | 登录用户管理作品、设置可见范围、管理坊客 | [个人工坊](/app/workshops) |
| 云乐坊上架 | 公开作品另行投稿、审核与上架；第三方入驻暂未开放 | [提交流程](/app/submission) |
| 统一登录 | 已登记的第一方客户端使用 SSO 0.6.2 | [SSO](/account/sso) |
| 云币与会员 | 已接入应用共用账户事实，具体权益由各应用定义 | [账户约定](/account/payment) |
| 原生 JSAPI | 在支持的 App 容器中按能力与来源授权调用 | [JSAPI](/app/jsapi) |

开发者套餐、在线 IDE、自助部署平台当前没有开放计划。接入状态以[官网应用生态](https://www.yunle.fun/developer)和实际入口为准，本站不承诺开放时间。

## 如何使用

第一次阅读从[快速开始](/guide/getting-started)进入。遇到问题先查[常见问题](/guide/faq)，需要交流未开放的接入需求时使用[官方联系入口](https://www.yunle.fun/docs/contact)。

产品帮助与用户条款在[官网帮助](https://www.yunle.fun/docs)，文档贡献方式见[文档维护](/guide/configuration)。
