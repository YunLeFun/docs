# 文档定位

`docs.yunle.fun` 是云乐坊面向外部开发者的公开文档站。

## 放什么

- 应用接入与提交说明。
- 应用审核、上架、更新、下线等公开规范。
- 统一账号、支付、云币、会员与 SSO 接入指南。
- 面向外部开发者的 API、SDK、参数、错误处理和接入 checklist。

## 不放什么

- 内部规划、草案和仓库职责决策。
- 管理后台操作 SOP、部署细节、密钥和权限流程。
- 产品实现过程中的临时笔记。

这些内容分别放在：

| 入口 | 职责 |
| --- | --- |
| [wiki.yunle.fun](https://wiki.yunle.fun) | 内部规划、决策记录、运营和部署 SOP |
| [www.yunle.fun/docs](https://www.yunle.fun/docs) | 官网帮助、产品说明、法律条款和轻量入口 |
| [apps.yunle.fun/docs](https://apps.yunle.fun/docs) | App 产品设计、数据库模型和移动端实现笔记 |

## 维护原则

对外文档必须稳定、可分享、可搜索、可长期引用。还未定稿的流程先保留在 Wiki，等稳定后再整理到本站。
