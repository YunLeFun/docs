# 快速开始

## 适用对象

如果你希望把自己的 Web 应用接入云乐坊，通常需要完成三件事：

1. 提交应用信息，让应用进入工坊审核流程。
2. 根据业务需要接入统一账号、云币、会员或 SSO。
3. 审核通过后，在工坊、寻乐或用户桌面中对外展示。

## 接入前准备

- 一个可公开访问的 Web 应用地址。
- 应用名称、简介、图标或 emoji、分类、GitHub 仓库信息。
- 如果需要平台计费能力，确认业务的 `appId`、扣费场景和幂等键规则。
- 如果需要统一登录，确认应用是否与云乐坊使用同一 CloudBase 环境和 Auth 体系。

## 推荐路径

1. 阅读 [应用接入概览](/app/)。
2. 按 [应用提交流程](/app/submission) 准备应用资料。
3. 对照 [审核与上架规范](/app/review) 自检。
4. 如需账号、支付或会员能力，阅读 [账号与支付概览](/account/)。

## 当前限制

云乐坊的开发者开放流程仍在逐步完善。若页面或接口尚未开放，请先通过云乐坊官方渠道联系维护者。
