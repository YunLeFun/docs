# 快速开始

先确认你要使用的能力，再选择对应路径。第三方自助上架与统一账号接入尚未开放，安装 SDK 不会自动获得接入权限。

## 浏览应用或读取目录

从[官网应用图谱](https://www.yunle.fun/explore)或[云乐坊 App](https://apps.yunle.fun)浏览已上架应用。如果要在服务端展示目录，使用[公开目录接口](/app/catalog)，无需登录或管理凭证。

## 管理自己的作品

1. 登录[云乐坊 App](https://apps.yunle.fun)，在应用创作入口准备作品资料；创建与更新要求正式账号、已验证手机号且账号可用。
2. 按[提交流程](/app/submission)填写 HTTPS 访问地址、隐私政策和支持入口，选择可见范围。
3. 保存后作品按所选范围在个人主页或个人工坊展示；需要云乐坊公开推荐时，另行投稿审核。

公开作品当前按第一方域名范围校验。个人工坊的坊客权限保护目录信息，应用网站自身仍需要实现登录和访问控制。详细规则见[个人工坊](/app/workshops)。

## 接入第一方统一登录

1. 确认维护者已经登记你的 `clientId`、HTTPS Origin、完整回调地址和 scope。
2. 使用 [SSO SDK](/account/sso)发起顶层跳转，在应用回调页消费一次性授权码。
3. 需要长期登录时，由应用服务端校验身份证明并创建自己的会话。
4. 在 App 内打开时，用 [JSAPI](/app/jsapi)探测能力；普通浏览器保留网页登录入口。

如还需要云币与会员能力，先确认[账户接入边界](/account/payment)。登录成功不会自动授予扣费、应用管理或原生授信权限。
