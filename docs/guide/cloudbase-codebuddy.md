# CloudBase 开发工具

CloudBase 与 CodeBuddy 的配置由其官方文档维护。本站保留这一入口，避免重复维护版本要求、安装命令和授权步骤。

- [CodeBuddy 配置指南](https://docs.cloudbase.net/ai/cloudbase-ai-toolkit/ide-setup/codebuddy)：插件、IDE 集成与环境登录。
- [CloudBase 文档](https://docs.cloudbase.net/)：SDK、数据库、云函数与认证。

这些工具用于开发和管理自己的云开发环境，安装它们不会获得云乐坊的 SSO、应用上架或账户服务权限。云乐坊接入条件见[快速开始](/guide/getting-started)。
