# SSO 与登录

云乐坊使用统一登录体系，子应用可以复用平台身份完成授权。

## 适用场景

- 子应用需要识别当前云乐坊用户。
- 子应用需要读取账户状态、云币余额或会员状态。
- 子应用需要在扣费前确认登录态。

## 基本原则

- 用户身份以 CloudBase Auth 的 uid 为准。
- 子应用不应自行伪造或传入用户 uid。
- 涉及扣费、会员判断和敏感操作时，应优先通过服务端或云函数校验。
- OAuth 回调、deeplink 和跨端状态处理由平台统一约定。

## Web 子应用

Web 子应用应接入平台统一 Auth，并在需要时调用账户中心接口获取当前用户状态。

## 原生 App 回调

移动端授权回调由 `apps.yunle.fun` 和 `www.yunle.fun` 协同处理。公开稳定的回调参数和错误码将在本页补齐。
