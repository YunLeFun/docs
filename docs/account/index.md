# 账号与支付概览

云乐坊的平台账户中心提供统一账号、云币、会员和支付能力。

## 核心概念

| 能力 | 说明 |
| --- | --- |
| 统一账号 | 基于 CloudBase Auth 的用户身份体系 |
| 云币 | 平台虚拟货币，可用于按次或按量消费 |
| 会员 | 平台级权益身份，跨应用共享 |
| 支付 | 统一微信支付链路，用于充值云币或购买会员 |
| SSO | 子应用复用云乐坊登录状态的授权流程 |

## 接入边界

平台负责维护账户事实：

- 用户身份。
- 云币余额。
- 会员等级与到期时间。
- 订单与流水。

应用负责维护业务规则：

- 哪些功能需要付费。
- 会员能解锁哪些功能。
- 每个业务动作的扣费数量。
- 扣费幂等键如何生成。
