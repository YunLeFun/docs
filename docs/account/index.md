# 账号与支付概览

云乐坊的已接入应用共享用户身份、云币余额和会员状态。应用自己的角色、内容权限和长期会话仍由应用维护。

| 能力 | 平台负责 | 应用负责 |
| --- | --- | --- |
| 登录 | 确认用户身份，向已登记客户端签发一次性 SSO 授权码 | 校验结果、建立和撤销自己的会话 |
| 云币 | 记录余额与流水，执行受控扣费 | 明确消费场景、价格、业务幂等键和失败处理 |
| 会员 | 记录有效状态、等级与到期时间 | 定义会员可用功能，在服务端校验权益 |
| 支付 | 在支持的官方入口处理充值与会员订单 | 引导用户完成购买，等待可信结果后刷新账户 |

## 当前接入条件

SSO 用于已经登记的第一方应用；云币与会员接口也需要已有的平台接入配置。公开 SDK 和本文档不提供自动注册或第三方计费授权。

匿名身份不能读取本人余额或执行账户消费。部分业务还要求已验证手机号和可用账号，前端显示的登录状态不能替代服务端检查。

- [云币与会员](/account/payment)：读取账户、权益判断与消费约定。
- [常见问题](/guide/faq)：登录、来源校验和账户调用排查。
