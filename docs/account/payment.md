# 云币与会员

云币和会员是云乐坊账户中心的两类资产。

## 云币

云币用于按次或按量消费。平台记录用户余额和流水，应用在需要消费时调用平台扣费能力。

关键规则：

- 云币余额跨应用共享。
- 每笔消费需要带应用标识 `appId`。
- 按次扣费建议提供业务幂等键 `bizId`。
- 余额不足时，应用应引导用户充值。

## 会员

会员是平台级权益身份。平台只回答用户是否为会员、会员等级和到期时间。

应用需要自行定义：

- 会员可以解锁哪些功能。
- 哪些按次消费对会员免费。
- 是否展示会员专属入口。

## 推荐消费流程

```ts
const account = await getAccount()

if (!account.membership?.isActive) {
  await deductCoin({
    appId: 'my-app',
    amount: 50,
    bizId: `feature:${taskId}`,
  })
}

runFeature()
```

## 充值

最简单的充值方式是引导用户前往云乐坊钱包页。后续如开放内嵌充值能力，以本页更新为准。
